# 五子棋 · Gomoku

一个零依赖的网页五子棋，使用原生 HTML + Canvas + JavaScript 实现。双击 `index.html` 即可开玩，也可以直接部署到 GitHub Pages。

## 功能

- 15 × 15 标准棋盘，支持双人对战与人机对战
- 鼠标悬停预览落子，最后一手高亮显示
- 五子连珠自动判定胜负，并高亮胜利连线
- 悔棋（人机模式下一次退回两步）与一键重开
- 界面自适应，支持高分辨率屏幕
- 人机 AI 基于棋型评分：活四、冲四、活三、眠三等威胁识别，会主动封堵与进攻

## 快速开始

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

如果希望用本地服务器预览：

```bash
# 任选其一
npx serve .
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 实现要点

- **渲染**：Canvas 2D 绘制棋盘与棋子，按 `devicePixelRatio` 缩放保证高清屏清晰度，`ResizeObserver` 跟随容器尺寸重绘。
- **胜负判定**：以落子点为中心向四个方向统计同色连子，达到 5 子即判胜。
- **AI 思路**：
  1. 只考虑已有棋子周围 2 格内的空点作为候选，减少搜索量。
  2. 对每个候选点，分别假设「我方在此落子」和「对方在此落子」，统计四个方向上的棋型得分。
  3. 最终得分 = 进攻分 + 防守分 × 0.9 + 中心倾向，取最高分落子；同分时随机选择，避免每局走法完全一致。
  4. 棋型分值：五连 > 活四 > 冲四 > 活三 > 眠三 > 活二，因此 AI 既能抢先成五，也会封堵对手的关键点。

## 部署到 GitHub Pages

1. 打开仓库的 `Settings` → `Pages`。
2. 在 `Build and deployment` 中选择 `Deploy from a branch`。
3. 分支选 `main`，目录选 `/ (root)`，保存。
4. 稍等片刻，即可通过 `https://<用户名>.github.io/wuziqi/` 访问。
